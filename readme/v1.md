## 🧠 PyResearch — Pothole Detection (v1 Overview)

### 🚀 Version: **v1 (Base Real-Time Detection System)**

> Release Date: **Oct 2025**
> Base Model: **YOLOv12 (best.pt)**
> Framework: **Flask + OpenCV + Ultralytics**

---

### 🧩 Key Features in v1

#### 🎥 **1. Core YOLOv12 Integration**

* Implemented **YOLOv12 (best.pt)** for pothole detection.
* Enabled **real-time frame-by-frame inference** directly from uploaded videos.
* Displayed **detections live** using an embedded video stream.

#### 💻 **2. Local Model Execution**

* Fully **offline model** running locally (no cloud dependency).
* Automatic device selection (GPU → CPU fallback).
* Optimized for Windows with OpenCV-based streaming.

#### 📊 **3. Live Metrics Dashboard**

* Displayed **Detections Count**, **Total Area (m²)**, and **Average Confidence** in real time.
* Added smooth auto-refresh UI every second.
* FPS calculation introduced for baseline performance measurement.

#### 📂 **4. Video Upload System**

* Flask form-based upload with drag-and-drop support.
* Allowed single video inference per session.
* Clean upload management using `/uploads` folder.

#### 📄 **5. Foundational UI Design**

* Minimal **HTML + CSS dashboard** with a blue theme.
* Live video feed rendered through Flask route `/video_feed`.
* Basic layout:

  * Left → Video Viewer
  * Right → Stats Panel
