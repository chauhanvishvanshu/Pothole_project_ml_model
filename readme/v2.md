

## 🧠 PyResearch — Pothole Detection (v2 Update Summary)

### 🚀 Version: **v2 (Hybrid Real-Time GPU Pipeline)**

> Release Date: **Nov 09, 2025**
> Base Model: **YOLOv12 (best.pt)**
> Environment: **Flask + OpenCV + Ultralytics**

### 🧩 Key Improvements in v2

#### ⚡ **1. Real-Time Hybrid Pipeline**

* Combined batch inference with continuous streaming for **smooth video playback**.
* Eliminated frame stutter or pause between YOLO detections.
* Maintained full accuracy with smarter GPU scheduling.

#### 🧠 **2. GPU-Optimized Processing**

* Enabled **CUDA + cuDNN tuning** (automatic GPU detection).
* Improved **processing FPS by 20–40%** on RTX 2050 GPUs.
* Added graceful CPU fallback (auto switch when GPU unavailable).

#### 🔁 **3. Multi-Run Upload Support**

* Can now **process multiple videos consecutively** without restarting the app.
* Resets internal states (logs, queues, threads) after every run.

#### 📊 **4. Enhanced Live Dashboard**

* Added **Video FPS**, **Processing FPS**, **Speed %**, and **ETA**.
* Color-coded performance status (🟢 Fast / 🟠 Moderate / 🔴 Slow).
* Dynamic updates every 1 second via async fetch (no flicker).

#### 📂 **5. Accurate Logging + Export**

* Frame-wise detection log (area, confidence, severity).
* Instant **CSV export** with unique timestamp per session.

### 🧾 Notes

* Use command below to verify GPU is active:

  ```bash
  python -c "import torch; print(torch.cuda.is_available(), torch.cuda.get_device_name(0))"
  ```
* If output is `False`, reinstall CUDA-enabled PyTorch:

  ```bash
  pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121
  ```
