# 🕳️ **Road-Watch — Intelligent Pothole Detection System**

### **v3 — Production Build (YOLOv12 + Flask + Automated Reporting)**

> 🚀 A fully automated, production-ready pothole detection system using **YOLOv12**, **Flask**, and **OpenCV**, featuring real-time detection, severity analysis, CSV report generation, ZIP archiving, and one-click setup/run scripts.

---

# 📘 **Overview**

**Road-Watch** processes uploaded road-inspection videos using **YOLOv12**, detects potholes frame-by-frame, measures area (m²), assigns severity, logs all detections, and generates:

✔ A clean CSV report
✔ A downloadable ZIP archive
✔ Live video output with annotated frames

v3 includes **backend stabilization**, **thread-safe inference**, **report guarantees**, and **full automation scripts** for Windows.

# 🎥 **How Road-Watch Works**

1. User uploads a video
2. Frames are streamed to a worker thread
3. YOLOv12 detects potholes → returns boxes
4. Each detection is logged:

   * Frame
   * Timestamp
   * Confidence
   * Area (m²)
   * Severity
5. Process continues until video ends
6. System generates:

   * CSV report
   * ZIP archive
   * Final summary

---

# 📊 **CSV Output Format (v3)**

**Filename:**

```
<videoName>_detections_YYYYMMDD_HHMMSS.csv
```

**Columns:**

| Column       | Meaning                           |
| ------------ | --------------------------------- |
| frame_number | Frame index                       |
| video_time_s | Timestamp in video                |
| timestamp    | Real-time clock                   |
| confidence   | YOLO confidence                   |
| area_m2      | Pothole area                      |
| severity     | Minor / Moderate / Major / Severe |

---

# 🧮 **Severity Rules**

| Area (m²) | Severity | Color  |
| --------- | -------- | ------ |
| `< 0.5`   | Minor    | Green  |
| `0.5–1.5` | Moderate | Yellow |
| `1.5–3.0` | Major    | Orange |
| `> 3.0`   | Severe   | Red    |
